Installation

Followed this guide and this one.
Download Proxmox ISO.
Check the hash if you’re paranoid: 
$ sha256sum proxmox*.iso
Plug in USB drive. Don’t mount it. I had to format the drive for some reason. I hadn’t started taking notes.
$ sudo fdisk -l
$ mkfs.exfat /dev/sdc
Write ISO to the drive.
$ sudo dd if=/home/damo/Downloads/proxmox-ve_9.2-1.iso of=/dev/sdc bs=1M status=progress
Plug the drive into what will be the Proxmox machine and boot from the drive. Start the GUI installer and follow the instructions. Follow the guides. Save important info (password, static IP address). Access Proxmox GUI through the browser: [static IP]:8006
